## 🚀 시작하기

### 폴더 구조
```
festival-website/
├── index.html          # 메인 웹사이트
├── config.json         # 모든 내용이 저장되는 설정 파일
├── admin/              # 관리 도구 (내용 수정 도구)
│   ├── index.html
│   ├── admin-style.css
│   └── admin-app.js
└── assets/             # 디자인 파일들
    ├── css/
    │   └── style.css
    ├── js/
    │   └── app.js
    └── images/         # 이미지를 여기에 넣으세요
```

### 웹사이트 열기

1. **메인 웹사이트 보기**
   - `festival-website/index.html` 파일을 더블클릭하여 브라우저에서 엽니다.
   - 이것이 방문자들이 보게 될 실제 축제 웹사이트입니다.

2. **관리 도구 열기**
   - `festival-website/admin/index.html` 파일을 더블클릭합니다.
   - 여기서 모든 내용을 쉽게 수정할 수 있습니다.

## 🛠️ 관리 도구 사용법

### 관리 화면 구성

관리 도구는 **왼쪽 메뉴**와 **오른쪽 내용 편집 영역**으로 구성되어 있습니다.

#### 왼쪽 메뉴
- 🎉 **기본 정보**: 축제 이름, 연도 등
- 🌟 **메인 화면**: 첫 화면에 보이는 내용
- 📅 **일정 관리**: 축제 일정과 장소
- 📰 **소식 관리**: 뉴스와 공지사항
- ℹ️ **소개 관리**: 축제 소개 섹션
- 🌤️ **날씨 정보**: 날씨 안내
- 🖼️ **갤러리**: 사진 관리
- 📱 **소셜 미디어**: SNS 링크
- 📋 **푸터 정보**: 하단 정보

#### 아래 버튼들
- 💾 **저장하기**: 변경사항을 config.json 파일로 다운로드
- 👁️ **미리보기**: 웹사이트를 새 탭에서 확인
- 📥 **내보내기**: 설정 파일 다운로드
- 📤 **가져오기**: 이전에 저장한 설정 불러오기

## ✏️ 내용 수정하기

### 1. 기본 정보 수정

1. 왼쪽 메뉴에서 **🎉 기본 정보**를 클릭
2. 다음 항목을 입력:
   - **축제 이름 (한국어)**: 예) 서울 봄꽃 축제
   - **축제 이름 (영어)**: 예) Seoul Spring Flower Festival
   - **태그라인**: 예) 봄의 향기가 가득한 축제
   - **연도**: 예) 2026

### 2. 메인 화면 수정

1. 왼쪽 메뉴에서 **🌟 메인 화면**을 클릭
2. 입력 항목:
   - **메인 타이틀**: 첫 화면 큰 제목
   - **서브 타이틀**: 작은 부제목
   - **스크롤 텍스트**: 스크롤 안내 문구

### 3. 일정 추가하기

1. 왼쪽 메뉴에서 **📅 일정 관리** 클릭
2. **축제 기간**에 날짜 입력
3. **+ 회장 추가** 버튼 클릭
4. 각 회장마다 다음 정보 입력:
   - **회장 이름**: 예) 메인 무대
   - **위치**: 예) 한강공원 여의도지구
   - **날짜**: 예) 4월 1일 ~ 7일
   - **시간**: 예) 10:00 - 22:00
   - **설명**: 회장에 대한 간단한 설명
5. 삭제하려면 **삭제** 버튼 클릭

### 4. 소식 추가하기

1. 왼쪽 메뉴에서 **📰 소식 관리** 클릭
2. **+ 소식 추가** 버튼 클릭
3. 입력 항목:
   - **날짜**: 발행 날짜
   - **제목**: 소식 제목
   - **카테고리**: 공지사항, 모집, 이벤트 등
   - **내용**: 소식 본문

### 5. 소개 섹션 추가하기

1. 왼쪽 메뉴에서 **ℹ️ 소개 관리** 클릭
2. **+ 섹션 추가** 버튼 클릭
3. 입력 항목:
   - **제목**: 섹션 제목
   - **내용**: 상세 설명

### 6. 날씨 정보 설정

1. 왼쪽 메뉴에서 **🌤️ 날씨 정보** 클릭
2. **날씨 타이틀**과 **설명** 입력
3. **+ 추천 추가** 버튼으로 준비물 추가
   - 예) "따뜻한 외투 필수"

### 7. 갤러리 관리

1. 왼쪽 메뉴에서 **🖼️ 갤러리** 클릭
2. **+ 이미지 추가** 버튼 클릭
3. 입력 항목:
   - **이미지 경로**: assets/images/gallery1.jpg
   - **설명**: 이미지 설명

> **참고**: 이미지는 `festival-website/assets/images/` 폴더에 복사한 후 경로를 입력하세요.

### 8. 소셜 미디어 링크

1. 왼쪽 메뉴에서 **📱 소셜 미디어** 클릭
2. 각 SNS의 전체 URL을 입력:
   - Twitter: https://twitter.com/your_account
   - Instagram: https://instagram.com/your_account
   - Facebook: https://facebook.com/your_page
   - YouTube: https://youtube.com/@your_channel

### 9. 푸터 정보

1. 왼쪽 메뉴에서 **📋 푸터 정보** 클릭
2. 입력 항목:
   - **조직 이름**: 주최 단체명
   - **주소**: 사무실 주소
   - **전화번호**: 연락처
   - **이메일**: 이메일 주소
   - **저작권 정보**: © 2026 Your Festival
3. **+ 링크 추가**로 추가 링크 생성

## 💾 저장 및 적용하기

### 변경사항 저장

1. 내용 수정 후 왼쪽 하단의 **💾 저장하기** 버튼 클릭
2. `config.json` 파일이 다운로드됩니다
3. 다운로드된 파일을 `festival-website/` 폴더에 복사하여 기존 파일을 교체합니다

### 변경사항 확인

1. **👁️ 미리보기** 버튼을 클릭하여 새 탭에서 웹사이트 확인
2. 또는 `festival-website/index.html`을 브라우저에서 새로고침

## 🌐 웹사이트 배포하기

### 방법 1: GitHub Pages (무료)

1. GitHub 계정 생성 (github.com)
2. 새 저장소(Repository) 생성
3. `festival-website` 폴더의 모든 파일 업로드
4. Settings → Pages에서 활성화
5. 제공된 URL로 접속 가능

### 방법 2: Netlify (무료)

1. Netlify.com에 가입
2. "New site from Git" 또는 드래그 앤 드롭으로 폴더 업로드
3. 자동으로 웹사이트 주소 생성
4. 커스텀 도메인 연결 가능

### 방법 3: 호스팅 서비스

1. 카페24, 가비아 등의 웹호스팅 서비스 구매
2. FTP로 파일 업로드
3. 도메인 연결

## 🖼️ 이미지 추가하기

### 이미지 준비

1. 이미지를 `festival-website/assets/images/` 폴더에 복사
2. 파일 이름은 영문으로 (예: venue1.jpg, gallery1.jpg)
3. 권장 크기:
   - 히어로 배경: 1920x1080px
   - 갤러리: 800x600px
   - 로고: 200x200px

### 이미지 적용

1. 관리 도구에서 이미지 경로 입력
2. 예: `assets/images/your-image.jpg`
3. 저장 후 확인

## ❓ 문제 해결

### 변경사항이 적용되지 않아요

**해결 방법:**
1. config.json 파일이 올바른 위치에 있는지 확인
2. 브라우저에서 **Ctrl+Shift+R** (Windows) 또는 **Cmd+Shift+R** (Mac)로 강제 새로고침
3. 브라우저 캐시 삭제

### 이미지가 표시되지 않아요

**해결 방법:**
1. 이미지가 `assets/images/` 폴더에 있는지 확인
2. 파일 이름이 정확한지 확인 (대소문자 구분)
3. 이미지 경로가 올바른지 확인
4. 이미지 형식은 jpg, png, webp 권장

### 모바일에서 레이아웃이 깨져요

**해결 방법:**
- 이미 반응형으로 제작되어 있습니다
- 브라우저 캐시를 삭제하고 다시 시도
- 다른 모바일 브라우저로 테스트

### 관리 도구에서 저장이 안 돼요

**해결 방법:**
1. 브라우저가 파일 다운로드를 차단했는지 확인
2. 브라우저 설정에서 팝업 차단 해제
3. 다른 브라우저로 시도

## 💡 유용한 팁

### 백업하기
- **정기적으로 config.json 파일을 백업**하세요
- 관리 도구에서 **📥 내보내기**로 백업 가능
- 날짜별로 파일명 변경 (예: config-2026-01-15.json)

### 테스트하기
- 변경 전에 항상 **미리보기**로 확인
- 여러 브라우저에서 테스트 (Chrome, Firefox, Safari)
- 모바일에서도 확인

### 성능 최적화
- 이미지 크기를 적절하게 조절 (1MB 이하 권장)
- 불필요한 섹션은 삭제
- 정기적으로 오래된 소식 정리

## 📞 도움이 필요하신가요?

이 시스템은 코딩 지식 없이도 쉽게 사용할 수 있도록 설계되었습니다.

**자주 하는 작업:**
1. 소식 추가: 관리 도구 → 소식 관리 → + 소식 추가
2. 일정 변경: 관리 도구 → 일정 관리 → 내용 수정
3. 사진 추가: images 폴더에 복사 → 갤러리에 경로 추가
4. SNS 변경: 소셜 미디어에서 URL 수정

**주의사항:**
- 항상 저장하기 버튼을 눌러야 적용됩니다
- 다운로드된 config.json을 원본 폴더에 복사해야 합니다
- 정기적으로 백업하세요
