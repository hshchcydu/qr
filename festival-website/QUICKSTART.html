쉬운 관리

코딩 불필요

1

웹사이트 확인하기

현재 폴더에서 index.html 파일을 더블클릭하여 열어보세요. 이것이 여러분의 축제 웹사이트입니다!

2

관리 도구 열기

admin 폴더 안의 index.html 파일을 열면 모든 내용을 쉽게 수정할 수 있는 관리 화면이 나타납니다.

3

내용 수정하기

관리 도구에서 축제 이름, 일정, 소식, 사진 등 모든 내용을 직관적인 양식을 통해 수정할 수 있습니다.

4

저장하기

수정 완료 후 💾 저장하기 버튼을 클릭하면 config.json 파일이 다운로드됩니다. 이 파일을 프로젝트 폴더에 복사하여 기존 파일을 교체하세요.

5

이미지 추가하기

assets/images/ 폴더에 사진을 복사한 후, 관리 도구에서 경로를 입력하세요. 예: assets/images/my-photo.jpg

6

배포하기

GitHub Pages, Netlify, 또는 일반 웹호스팅에 업로드하여 전 세계에 공개하세요! 자세한 방법은 사용설명서를 참고하세요.

⚠️ 중요!

변경사항을 적용하려면 반드시 "저장하기"를 클릭하고, 다운로드된 config.json 파일을 원본 폴더에 복사해야 합니다.
